# 問い合わせ対象外の一括操作

## 目的

問い合わせ対象外ドメインの登録は、個別問い合わせの管理情報ではなく問い合わせ一覧からまとめて行う。

## UI

- 顧客未特定の問い合わせ行に対象外選択チェックボックスを表示する。
- 顧客特定済みの問い合わせは対象外候補として選択できない。
- 一覧ヘッダーのチェックボックスで、現在の絞り込み結果に表示されている顧客未特定問い合わせを一括選択・解除できる。
- 1件以上選択すると `選択を対象外 (N)` を実行できる。
- 管理情報にあった個別の `問い合わせ対象外` 操作は表示しない。
- 顧客登録と顧客担当者登録は従来どおり管理情報から行う。

## 対象外登録

選択した問い合わせごとに、その問い合わせを開始した最初の受信メールの送信元ドメインを取得する。

取得したドメインを `INQUIRY_EXCLUDED_DOMAINS` へ重複なく追加する。同じドメインの問い合わせを複数選択してもドメインは1件として登録する。

対象外は問い合わせ単位ではなくドメイン単位で適用される。そのため選択していない問い合わせでも、同じドメインから開始した問い合わせは一覧・ダッシュボードから除外される。

問い合わせ・メールデータ自体は削除しない。設定からドメインを外せば再表示できる。

処理直前に顧客が特定済みになった問い合わせや、送信元ドメインを取得できない問い合わせはスキップし、他の選択分は処理する。
