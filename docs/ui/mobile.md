# モバイルUI仕様

## 1. 目的

スマートフォンからダッシュボード確認、問い合わせ確認・更新・返信、マスタ参照・編集を行えるようにする。

PC向けの一覧性をそのまま縮小せず、モバイルでは一画面一操作を優先する。

## 2. 共通

- 760px以下をモバイルレイアウトとする。
- ヘッダーは縦方向に再配置し、主要ナビゲーションを3分割ボタンとして表示する。
- 入力欄はモバイルブラウザで意図しない拡大が起きにくい文字サイズとする。
- 主要ボタンは指で操作しやすい高さを確保する。
- 横スクロールを基本操作にしない。

## 3. ダッシュボード

- KPIは2列、狭い端末では1列に切り替える。
- 最近の問い合わせは縦積みカード表示とする。
- マスタ登録状況・デプロイ情報は1列表示とする。

## 4. 問い合わせ

### 4.1 一覧

PCの6列テーブルをそのまま縮小せず、モバイルでは問い合わせ1件をカード形式で表示する。

カードには以下を表示する。

- 受信日時
- 顧客
- 件名
- 担当
- 状態
- 期限

### 4.2 詳細

問い合わせを選択すると詳細を全画面表示する。

- 上部に「問い合わせ一覧へ戻る」を固定表示する。
- 基本情報フォームは1列表示とする。
- AI要約操作、返信操作、メール履歴も同じ詳細画面内で利用できる。
- 返信送信時の確認仕様はPCと共通とする。

## 5. マスタ管理

- マスタ種別は横スクロール可能なタブとして表示する。
- 一覧から編集対象を選択した場合、編集画面を全画面表示する。
- 上部に「マスタ一覧へ戻る」を固定表示する。

## 6. PCとの責務分離

モバイル固有の表示変更は `MobileStyles.html`、画面遷移補助は `MobileScript.html` に集約し、問い合わせやマスタの業務ロジック自体はPCと共通利用する。
