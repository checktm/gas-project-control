# 問い合わせ管理 UI仕様 v0.1

## 1. 目的

受信メールから自動登録された問い合わせを、PM・管理者が一覧で把握し、顧客特定、担当割当、状態更新、次回対応管理まで一画面で行えることを目的とする。

## 2. 画面構成

アプリ上部の主要機能切替に以下を持つ。

- ダッシュボード
- 問い合わせ
- マスタ管理

問い合わせ画面は、左側の一覧と右側の詳細・編集領域の2ペイン構成とする。

PCでは右側詳細を「管理情報」と「コミュニケーション」に分ける。管理情報は保存ボタンまでを一画面内で確認・操作できる密度を優先し、メール履歴や返信のために詳細ペイン全体を長くスクロールさせない。

## 3. 問い合わせ一覧

表示項目:

- 最終受信日時
- 顧客名
- 顧客担当者または送信元
- 件名
- 自社担当者
- 状態
- 対応期限
- 優先度

顧客未特定の場合は「未特定」と明示する。

一覧は画面内で独立して縦スクロールできる。受信日時と件名は一覧性を優先し、件名は可能な範囲で2行まで表示する。

### 3.1 絞り込み

- フリーワード検索
  - 顧客名
  - 顧客担当者
  - メールアドレス
  - 件名
  - 概要
  - 分類
- 状態
- 優先度
- 顧客未特定のみ

## 4. 詳細・編集

一覧行を選択すると、右ペインに問い合わせ詳細を表示する。

編集可能項目:

- 顧客
- 顧客担当者
- 状態
- 優先度
- 自社担当者
- 分類
- 対応期限
- 概要
- 次回対応

PCでは、問い合わせヘッダー、各管理項目、概要、次回対応、保存ボタンまでを原則として一画面内に収める。概要・次回対応は一覧性を優先して低めの入力欄とし、必要時は利用者が入力欄を拡大できる。

受信情報として保持する以下は画面から編集しない。

- Gmail message ID
- Gmail thread ID
- メール本文
- 送信元
- 受信日時

## 5. 顧客・担当者

顧客を変更した場合、顧客担当者候補は選択した顧客に属する担当者へ絞り込む。

自動判定結果は以下を表示する。

- 担当者一致
- ドメイン一致
- 候補複数
- 顧客未特定
- 手動設定

利用者が顧客を変更した場合は `MANUAL` として保存する。

顧客未特定・候補複数の問い合わせは、現在の顧客・顧客担当者マスタを使って再判定できる。

## 6. 返信・メール履歴

詳細下部のコミュニケーション領域は、PCでは以下のタブ切替とする。

- 返信
- メール履歴

問い合わせを選択した直後は「返信」を優先表示する。これにより、利用者が過去メール履歴の末尾までスクロールせず返信操作へ移れるようにする。

### 6.1 返信

- 最新の受信メールを返信元とする
- 返信先を表示する
- 本文入力
- 送信前確認
- Gmailの同一スレッドへ返信
- 送信後はInquiryMessagesへOUTBOUNDとして保存

### 6.2 メール履歴

同一Inquiryへ紐づくInquiryMessageを**新しい日時順**で表示する。

表示内容:

- 受信 / 送信
- 件名
- メール日時
- プレーンテキスト本文

受信 / 送信は文字サイズを変えず、バッジ形式で視認しやすく表示する。メールアドレスは方向ラベルには併記しない。

PCではメール履歴タブの領域だけを独立してスクロールさせる。問い合わせ管理フォームや保存ボタンをメール履歴スクロールの影響で見失わない構成とする。

## 7. AI要約

概要欄の近くに「AIで要約」を表示し、メール履歴から概要候補を生成できる。

AI生成結果は自動保存せず、利用者が内容を確認して保存する。既存概要がある場合は置換前に確認する。

## 8. 保存

保存時はスプレッドシート `Inquiries` の管理項目のみ更新する。

参照整合性として以下を検証する。

- customer_id が Customers に存在すること
- contact_id が CustomerContacts に存在すること
- contact_id が選択customer_idに属すること
- assigned_member_id が Members に存在すること
- status / priority が定義済みコードであること

## 9. モバイル

スマートフォンでは一覧から問い合わせを選択すると詳細を全画面表示し、「問い合わせ一覧へ戻る」で一覧へ戻れる。

返信とメール履歴はPCと同じタブ概念を維持し、縦方向の操作に適したレイアウトとする。

## 10. 空状態

問い合わせが0件の場合は、メール取込設定後に自動登録される旨を表示する。

一覧未選択時は、右ペインに問い合わせ選択を促す表示を出す。

## 11. v0.1対象外

- 添付ファイル表示
- 問い合わせの手動新規作成
- 問い合わせ削除
- AIによる自動分類・自動優先度確定
- SLA自動計算
- Project / Taskへの直接変換UI
