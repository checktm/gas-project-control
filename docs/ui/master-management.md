# マスタ管理画面仕様 v0.1

## 1. 目的

問い合わせ管理で利用する基礎データをWeb画面から保守できるようにする。

ガントチャートは現段階では画面から非表示とし、主要ナビゲーションは以下とする。

- 問い合わせ
- マスタ管理

ガント関連の既存仕様・ソースは将来再利用できるよう削除しない。

## 2. マスタ管理対象

v0.1では以下を画面管理対象とする。

1. 顧客
2. 顧客担当者
3. 社内メンバー
4. 問い合わせ分類
5. システム設定

問い合わせ状態・優先度は業務ロジックと直接結びつく固定コードであるため、v0.1では任意変更可能なマスタにはしない。

## 3. 顧客

管理項目:

- 顧客名
- メールドメイン
- 状態（ACTIVE / INACTIVE）
- 備考

メールドメインは問い合わせメール送信者からの顧客自動判定に利用する。
削除ではなく無効化を基本とする。

## 4. 顧客担当者

管理項目:

- 顧客
- 担当者名
- メールアドレス
- 電話番号
- 有効 / 無効

メールアドレスは顧客担当者自動判定に利用するため、重複登録を許可しない。

## 5. 社内メンバー

管理項目:

- メンバー名
- メールアドレス
- 有効 / 無効
- 表示順

問い合わせの自社担当者として利用する。

## 6. 問い合わせ分類

`InquiryCategories` シートを使用する。

列:

- category_id
- category_name
- active
- display_order
- updated_at

問い合わせ詳細画面では自由入力ではなく、このマスタから分類を選択する。

## 7. システム設定

画面から変更可能な設定は安全性のため以下に限定する。

- INQUIRY_GROUP_ADDRESS
- MAIL_SEARCH_QUERY
- MAIL_IMPORT_MAX_THREADS
- MAIL_IMPORT_ENABLED

その他のSettings値は画面から任意編集させない。

## 8. UI

マスタ管理画面は以下の3領域を基本とする。

- 左: マスタ種類選択
- 中央: 一覧・検索
- 右: 選択項目の編集 / 新規登録

ノートPCでの一覧性を優先し、原則としてモーダルを使用しない。

## 9. データ保全

- 各参照には安定したIDを使用する。
- 使用済みデータの物理削除はv0.1では行わない。
- 顧客、担当者、メンバー、分類は無効化で運用する。
- システム設定は許可されたキーのみ変更可能とする。
