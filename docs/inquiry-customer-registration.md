# 問い合わせメールからの顧客登録

## 目的

問い合わせのメール履歴を確認している途中で、送信元ドメインを新しい顧客としてその場で登録できるようにする。

## UI

受信メールの送信元ドメインが既存Customersに登録されていない場合、メールカードに `顧客登録` を表示する。

押下すると顧客登録ダイアログを開き、以下を表示する。

- 顧客名: 利用者が入力
- ドメイン: 対象メールのFromアドレスから取得し、編集不可
- 送信元メールアドレス: 確認用表示

登録済みドメインの場合は新規登録ボタンを表示せず、登録済みであることを表示する。

## 登録処理

- 対象は受信メールのみ
- メールが現在のInquiryに属することをサーバー側で再確認する
- Fromアドレスからドメインを抽出・正規化する
- 同一ドメインのCustomerが既に存在する場合は重複登録しない
- 新規CustomerはACTIVEで作成する
- 問い合わせが顧客未設定の場合のみ、作成したCustomerをその問い合わせへ自動設定する
- 問い合わせに既に顧客が設定されている場合は、その設定を上書きしない
- 顧客担当者は自動作成しない

これにより、メール履歴に複数の外部送信者が含まれる場合でも、既存の問い合わせ顧客を不用意に上書きせずに顧客マスタだけを追加できる。
